# water_areas_shapefiles

This repository contains the water areas shapefiles in various regions.
* When available for direct download from an official website, the shapefile integrity is maintained without any modification.
* When not available for direct download, each water area has been created based on offical information available on official websites from countries agencies (i.e. Ministry of Fisheries) or RFBs, insititutions,etc. Metadata for these created shapefiles uses the water_areas_vocabulary fields as attributes (i.e., area code, area name, namespace) together with the source of the water area.
